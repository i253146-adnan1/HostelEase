## Architecture & Module Design
- `hostel.models`:
  - `Room`: `room_number` (unique `CharField(max_length=20)`), `capacity` (`PositiveIntegerField` with `MinValueValidator(1)`), `created_at`, `updated_at`. Properties: `occupancy` (active assignment count), `is_full` (`occupancy >= capacity`), `available_slots` (`capacity - occupancy`). Class method `get_pending_request_count()` returns `0` as a placeholder for VS-11 Dashboard integration (ADR-005).
  - `RoomAssignment`: `room` (`ForeignKey(Room, on_delete=PROTECT, related_name='assignments')`), `student_id` (`CharField(max_length=50, db_index=True)` — logical reference, no cross-module FK to `Student`), `assigned_at`, `is_active` (`BooleanField(default=True)`).
- `hostel.services` & `hostel.room_service` (service interface per `docs/contracts/VS-03-room-service-contract.md`):
  - `hostel.services`: `assign_student_to_room(room_id, student_id)` (transactional `select_for_update()` lock, raises `ValueError` if full, deactivates prior active assignments, creates active `RoomAssignment`), `clear_student_room_assignment(student_id)` (soft-deactivates `is_active=False`), `get_room_occupancy(room_id)`, `can_remove_room(room_id)`, `get_pending_request_count()`.
  - `hostel.room_service`: `list_rooms`, `get_room`, `create_room`, `update_room`, `get_occupancy`, `get_student_room`, `assign_student`, `clear_student_room` with `RoomError`, `RoomNotFoundError`, and `RoomFullError` used by VS-02 student registration.
- `hostel.forms`:
  - `RoomForm`: Validates `capacity >= 1` and blocks reducing `capacity` below `instance.occupancy` on edit.
- Views, URLs & Templates (`hostel/views.py`, `hostel/urls.py`, `templates/hostel/`):
  - Warden-only views guarded by `_warden_required` (redirects non-staff/unauthenticated users to `/accounts/login/`, matching ADR-003): `room_list`, `room_detail`, `room_create`, `room_edit`, `room_delete` (POST only; checks `can_remove_room` and catches `ProtectedError`), `room_assign` (POST only), `room_clear_assignment` (POST only).
  - Templates: `room_list.html` (`X / Y` occupancy display, `FULL` badge), `room_detail.html` (active assignments & clear/assign forms), `room_form.html` (shared create/edit form with inline errors).
