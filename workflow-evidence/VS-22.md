## Scope Delivered
- Added `avatar = models.ImageField(upload_to='avatars/', blank=True, null=True)` to `accounts.User` and generated migration `accounts/migrations/0003_user_avatar.py`.
- Verified `Pillow==13.0.0` in `requirements.txt`, `MEDIA_URL` / `MEDIA_ROOT` in `config/settings.py`, `DEBUG` media serving in `config/urls.py`, and `media/` in `.gitignore`.
- Added service layer in `accounts/services.py` (`validate_avatar_file`, `update_user_avatar`, `remove_user_avatar`) enforcing `JPG/JPEG`, `PNG`, `WEBP` formats, `<= 2 MB` max size, Pillow image integrity verification, and automatic deletion of replaced/removed avatar files from local storage.
- Added `@login_required_guard` endpoints in `accounts/views.py` and `accounts/urls.py` (`avatar_settings`, `avatar_upload`, `avatar_remove`), strictly scoped to `request.user` for both Students and Wardens.
- Added `templates/accounts/avatar_settings.html` with live client-side image preview, file picker, **Save Photo**, and **Remove Photo** actions, and updated `templates/base.html`, `templates/accounts/student_dashboard.html`, `templates/accounts/warden_dashboard.html`, and `templates/accounts/student_profile.html` to render circular avatar thumbnails (`object-fit: cover`) with clean initials fallback when unset.
- Added automated test suite in `accounts/test_avatar_vs22.py` covering Student and Warden upload/replace/remove with file cleanup, `302` redirect for unauthenticated requests, invalid format/corrupt image and `> 2 MB` rejection without corrupting existing avatars, and dashboard/`base.html` rendering with and without an avatar.
